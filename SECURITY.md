# Security Policy & Integrity Pledge

## 🛡️ Security Pledge
At **Noti-Fixer for Chinese Devices**, user privacy and device integrity are non-negotiable foundations.

- **Zero Telemetry:** Noti-Fixer contains zero tracking pixels, analytics calls, or remote command execution.
- **Local Execution:** 100% of operations run strictly between your computer's local shell and your phone via authenticated ADB.
- **DRM & Banking Preserved:** Because no bootloader unlocking or kernel rooting is performed, SafetyNet, Play Integrity API, and Widevine L1 remain unmodified and secure.

---

## 🔒 Reporting a Vulnerability

If you discover any security concern or potential vulnerability in Noti-Fixer scripts:

1. **Do not disclose publicly.**
2. Email the lead architect: **Mohammed Thuhidul Islam Shovo** via [GitHub Profile](https://github.com/shovo127) or create a private security advisory on GitHub.
3. We will respond within 48 hours with a reproduction assessment and patch roadmap.
